How this page treats imperfect recordings
  • Archive first: WAV files remain available because they are the most useful source artefacts.
  • Web playback second: MP3 files are used where available because browsers stream them more efficiently.
  • Technical notes matter: a near-clipping peak, low RMS level, or wide crest factor is not shameful. It is diagnostic information.
  • Waveform on demand: audio is decoded only when the waveform button is clicked, keeping the page fast.

Sphere Machine

At low RPM you see the object. At high RPM many complete orientations are superposed into one visible form. The same orientations are then used to estimate the probability that each point in space is occupied.

This extends the Infinite Camera idea in Spherism: not just “does the object look spherical?”, but “what spatial probability field is produced when orientation is averaged away?”

A) How the sphere is built

Average the object over rotations.

Let B be the object and 1B(x) its indicator: 1 inside the object and 0 outside. Define the rotational occupancy field:

PS(x) = ∫SO(3) 1B(R−1x) dμ(R)

Because the averaging measure over rotations is itself rotationally invariant, PS(Qx) = PS(x) for every rotation Q. Therefore the averaged field can depend only on radius:

PS(x) = p(r),   r = ‖x‖

That is the precise reason the superposition becomes sphere-like: orientation information is averaged away and radial structure remains.

B) Probability and the QM bridge

Borrow the probability language, not quantum mystique.

In this simulation p(x) is classical: it is the fraction of sampled orientations for which a spatial point lies inside the object.

p(x) = (# sampled orientations occupying x) / (# orientations sampled)

Quantum mechanics also represents spatial presence probabilistically. For a density operator ρ:

PQ(x) = ⟨x|ρ|x⟩

A rotationally averaged quantum state can be written as:

ρ̄ = ∫SO(3) U(R)ρU(R)† dμ(R)

The analogy is therefore symmetry averaging → radial probability structure. The important difference is that genuine quantum superposition involves amplitudes, phase and interference. Sphere Machine does not simulate those.

Quantum comparison

Hydrogen 1s is the clean reference case.

|ψ1s(r)|² = (1 / πa₀³) e−2r/a₀

The local probability density is spherically symmetric and highest at the centre. The radial-shell probability differs because a shell contains more volume as r increases. That is why this demo shows both local occupancy and relative shell mass.

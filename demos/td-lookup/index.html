How this GitHub version works

  • The interface is entirely static and can run on GitHub Pages.
  • Boundary lookup uses official Irish ArcGIS services in the browser.
  • Representative contact files are stored locally in this repo and can be refreshed by workflow.
  • South Dublin County Council currently uses a council-directory fallback unless refreshed separately.

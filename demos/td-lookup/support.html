Support Dublin Representative Finder

Dublin Representative Finder is an open civic lookup tool. The code is public. Funding supports maintenance, data refreshes, accessibility, quality assurance, and future expansion.

Open the demo View code Issue forms

What support funds

  • Routine maintenance and bug fixing
  • Bundled representative contact-data refreshes
  • Accessibility, mobile usability, and interface hardening
  • Clearer provenance, documentation, and update workflow
  • Evaluation of wider geographic coverage beyond the current Dublin-first demonstrator

Suitable funding routes

This demonstrator is better suited to sponsorship, civic-tech support, academic or public-engagement backing, and small institutional co-funding than to a closed product model.

  • individual sponsorship
  • small civic-tech or public-interest grants
  • institutional collaboration
  • local democracy and participation support

Current collaboration channels

Use structured issue forms for concrete improvements and GitHub Discussions for broader ideas, use cases, and collaboration around future directions.

  • lookup or boundary bug
  • representative data correction
  • feature or coverage request
  • co-funding or demonstration partnership

Suggested sponsorship framing

The cleanest framing is not “pay for private code.” It is “support stewardship of an open civic utility.”

  • Base support: keep the demonstrator maintained and current
  • Development support: fund accessibility, QA, and documentation improvements
  • Expansion support: assess extension beyond the current Dublin-first scope

Project principles

  • The code remains public.
  • Support funds maintenance and public value, not paywalling.
  • Sponsorship does not imply party-political alignment.
  • Changes should remain transparent, documented, and reviewable.

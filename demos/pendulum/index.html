Pendulum wave principle

The pendulum wave uses calibrated lengths. Each pendulum completes a different integer number of oscillations within the same cycle window, so the array repeatedly slips out of phase and re-aligns.

Useful correction

In an ideal simple pendulum, the period is controlled mainly by length, not by bob mass: T ≈ 2π√(L/g). The bob sizes are visual cues unless damping or non-ideal effects are added.

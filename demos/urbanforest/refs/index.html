The on-page carbon tool uses the UrbanForest site documents for footprint, density, and palette context, then applies a cautious scenario curve for a temperate urban tiny-forest setting. It now supports both whole-site and per-m² views, with a static reference-case diagram for the Trinity-sized scenario. It should be treated as illustrative, not as formal carbon accounting.

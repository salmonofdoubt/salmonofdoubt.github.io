Case-study page

What the main UrbanForest page does

The main page is designed as a public case study, not a light project announcement. It combines narrative, evidence, methods, diagrams, and links so the intervention can be inspected rather than merely admired.

Core sections

  • Story: why the project exists and what was built.
  • Method: how the site was prepared and planted.
  • Species: final shrubs and trees used in the implemented palette.
  • Milestones: proposal, preparation, planting, recognition, and next steps.
  • Carbon: a scenario explorer, not a carbon-credit calculator.
  • Gallery: visual evidence from documents, preparation, and recognition.
  • Wellbeing: agency, connection, attention, and legacy.
  • Evidence: internal files, public coverage, and research continuation.

Design logic

The page is structured to show that a small urban forest can be understood as more than tree planting. It is a place-based intervention with ecological, educational, social, and research value.

The microsite also acts as a reusable template for future compact urban greening projects: document the site, explain the method, show evidence, disclose assumptions, and connect the intervention to wider research.

UrbanForest News

How the news radar works

The News page is a daily, source-led radar. It does not try to capture every mention of trees online. It prioritises useful signals that can help someone understand, design, fund, maintain, evaluate, or explain compact urban forest interventions.

Lane 1

Practical Urban Forests in Ireland

Irish examples, delivery signals, local authority action, campus greening, community planting, pocket forests, and implementation news.

Lane 2

Similar latitudes and temperate cities

Transferable examples from the UK, western Europe, northern Europe, maritime cities, and comparable temperate settings. Latitude and climate are more useful than longitude for ecological transfer.

Lane 3

Urban forest research and evidence

Research, evaluation, biodiversity, wellbeing, maintenance, survival, governance, and design lessons.

Important distinction

The live UrbanForest case study links to the microsite because it is a web-based project record. The CBSM item links to Zenodo because it is a working paper. The radar therefore separates site-native usefulness from research-paper evidence.

Ranking mechanism

How usefulness is scored

The ranking is rule-based and transparent. It is not an artificial intelligence judgement. The score is designed to bring practical, relevant, and recent items to the top while keeping useful background references available.

Signal What it does Current effect
Base relevance Items must match an urban forest, pocket forest, tiny forest, micro forest, Miyawaki, campus forest, community forest, urban woodland, native planting, or nature-based signal. Starts relevant items from a base score.
Core phrase match Strong phrases such as urban forest, pocket forest, tiny forest, or Miyawaki add weight. Rewards topic specificity.
Practical terms Terms such as implementation, maintenance, monitoring, biodiversity, wellbeing, community, campus, native, survival, case study, evidence, research, funding, and grant add points. Favours useful practice and evidence over vague green news.
Source trust Each source has a trust value in the source registry. Higher-trust sources receive a modest score boost.
Geographic and source scope Irish practice, institutional sources, and practice-oriented sources receive additional weight. Keeps the radar aligned with the UrbanForest use case.
Freshness Items inside the freshness window are marked fresh. Older items can remain as reference/background material. Recent items rise, but useful references are not automatically discarded.
Off-topic exclusions Terms such as wildfire, deforestation, logging, stock market, film, or unrelated forest stories are filtered out. Reduces noisy false positives.

Current scoring behaviour

  • Items below the minimum score are excluded from the latest feed.
  • The latest feed is capped so the page remains readable.
  • Curated items are merged with discovered items before sorting.
  • Duplicate IDs are removed so the same item does not appear twice.
  • Items are sorted by score and then by date where available.

Why this approach

The ranking mechanism is deliberately simple enough to inspect. Its purpose is not to declare objective importance. Its purpose is to create a practical shortlist that is good enough for daily review.

This makes the radar more like a research assistant than a news publisher: it finds, groups, and prioritises candidate items, but interpretation remains human.

Archive

How the daily archive works

Each refresh writes the current radar to a latest file and also stores a dated archive snapshot. This gives the news page memory.

Latest feed

The page reads data/news.json. This file contains the current generated timestamp, the section definitions, the note shown on the page, and the latest ranked items.

Dated snapshots

Each run writes a dated file under data/archive/ and updates data/archive/index.json. The archive index lets the page show a growing list of daily snapshots.

Governance

What is automatic and what remains human

Automatic

  • Fetch configured RSS feeds and selected source pages.
  • Extract titles, URLs, summaries, and dates where available.
  • Apply rule-based relevance scoring.
  • Group items into the three lanes.
  • Merge curated reference items.
  • Write latest JSON and dated archive files.

Human

  • Decide which items are genuinely useful.
  • Improve the source registry over time.
  • Adjust scoring if the radar becomes noisy.
  • Interpret research and practice implications.
  • Use the radar as a starting point, not as final editorial judgement.

Limits

What this system does not claim

The radar is not a systematic literature review, not a peer-review process, and not a complete global news monitor. It is a practical discovery tool for a public UrbanForest microsite. The ranking system is transparent and adjustable, but it should not be treated as an objective measure of scientific quality or public importance.

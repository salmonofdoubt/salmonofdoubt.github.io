Grant Radar

Track grants and calls in the nature, ecology, biodiversity, environmental, climate and energy space. Filter first by purpose, then narrow by applicant type, access route, grant scale, change state, and deadline timing.

This GitHub Pages version is intentionally static in the browser. The interface reads a generated JSON catalogue, so it stays fast and deployable while a scheduled harvester refreshes the underlying data.

How this GitHub version works

  • The interface is entirely static and can run inside /demos/grant-radar/.
  • A Python harvester writes a JSON catalogue that the site reads directly.
  • The harvester can run locally or on a scheduled GitHub Actions workflow.
  • Change detection compares the newest crawl with the previous saved catalogue.
  • The seeded dataset now includes community-scale, energy, local-authority-routed, entrepreneurship, and major research funding examples.

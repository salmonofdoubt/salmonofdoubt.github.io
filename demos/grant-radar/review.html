Grant Radar review layer

Discovery candidates

Use the suggest box on a candidate to open a GitHub request issue. The workflow then creates a reviewable CL draft. In the issue, tick either Accept promotion into trusted catalogue or Reject suggestion. Accept promotes the candidate into the main catalogue. Reject clears the suggestion state.

This version deduplicates multilingual and structurally repeated candidates, hides completed items by default, and uses a separate review.js file.

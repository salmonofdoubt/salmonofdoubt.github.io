Geo Radar

A geoscience-specific funding radar tuned to an experienced GFZ/Potsdam-style research profile: geochemistry, gas analytics, hydrogen, subsurface storage, geothermal systems, wetland interfaces, and sustainability-facing collaboration routes.

This version stays static in the browser and reads a generated JSON catalogue. It is designed to be fast, portable, GitHub Pages-friendly, and easy to fork for one researcher, one lab, or one thematic niche. The source set now explicitly includes GFZ careers monitoring.

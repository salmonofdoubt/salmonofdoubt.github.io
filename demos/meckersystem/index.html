02 · Systemlogik

Jeder Agent ist simpel. Die Gesellschaft nicht.

Die Agenten kennen nur ihren eigenen Zustand und Signale aus ihrer unmittelbaren Nachbarschaft.

1

Heterogenität

Jeder Agent erhält leicht andere Reiz-, Mecker- oder Beruhigungsschwellen.

2

Lokale Kontakte

Signale laufen nur entlang der sichtbaren Netzwerkverbindungen, nicht an „die Gesellschaft“.

3

Verzögerung

Agenten reagieren auf ältere Signale. Das kann Gegenkopplung zu spät eintreffen lassen.

4

Makromuster

Kaskaden, Cluster und kollektive Ruhe werden erst aus allen lokalen Zuständen sichtbar.

Mecker-Agent iMᵢ(t+1) ← eigener Reiz + Meckern der Nachbarn − Beruhigung der Nachbarn − Abklingen
Na-wird-schon-Agent jNⱼ(t+1) ← verzögertes Meckersignal der Nachbarn − eigene Erholung

03 · Warum ist das stärker?

Das Interessante existiert erst auf der Ebene des Kollektivs.

Ein einzelner Agent kann nur meckern, schweigen oder beruhigen. Er besitzt keine Regel für eine „Mecker-Kaskade“, eine „Clusterbildung“ oder eine „synchronisierte Welle“. Solche Zustände können nur entstehen, wenn viele unterschiedliche Agenten über ein Netzwerk gekoppelt sind.

Das ist weiterhin ein bewusst vereinfachtes agentenbasiertes Modell. Es demonstriert schwache Emergenz: Makroverhalten, das aus Mikroregeln berechnet werden kann, aber nicht als Makroregel im einzelnen Agenten steckt. Genau dafür ist die MeckerGesellschaft nun gebaut.

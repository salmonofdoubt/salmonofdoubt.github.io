Demos

Interactive public prototypes, concept sites, and small decision-support tools. Each demo lives in its own folder so it can mature independently or later split into a standalone repository.

The emphasis is practical: transparent logic, inspectable data, and public-facing interfaces that explain the idea without hiding the machinery.

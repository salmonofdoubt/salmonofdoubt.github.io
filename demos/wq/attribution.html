Data sources and caveats

This demo uses public environmental data and keeps provenance visible inside the app.

Primary sources

OPW waterlevel.ie. Latest hydrometric GeoJSON, station data and CSV time series. Contains Irish Public Sector Information licensed under CC BY 4.0.

Environmental Protection Agency. Bathing Water API, WFD Open Data API and Geoportal datasets. EPA API data are licensed under CC BY 4.0 where stated by the source.

Marine Institute. ERDDAP datasets are planned for marine shore and coastal context expansion.

OpenStreetMap contributors. Base map tiles and map context.

Important caveats

Hydrometric data are provisional and can be delayed. Bathing-water chemistry is latest official sample data, not continuous live sensing. WFD and groundwater status are contextual assessment data unless explicitly labelled otherwise.

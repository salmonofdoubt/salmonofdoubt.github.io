# P(HI) Judgement Lab

Static browser demo for human-led decision support.

Public path: /demos/phi/

Purpose:
P(HI) Judgement Lab helps users structure a decision, compare options, audit bias, prepare an NbS/SDSS evidence check, and generate a traceable decision memo.

Workflow:
P(HI) structures -> AI critiques -> human decides.

Privacy and architecture:
- Static site
- No backend
- No login
- No database
- No AI API call
- Local browser execution

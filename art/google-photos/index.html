Google Photos integration

DiAndré Art Manager Local

A personal studio tool for organising artworks, studies and reference photographs. Its Google Photos connection lets the artist choose individual photos or videos and import copies into a local artwork catalogue.

Runs on the artist’s own Mac Select-only Google Photos access

What the application does

The Art Manager runs locally at http://localhost:8000/art/manage/. It is not a public login service. The public DiAndré Art gallery is a separate, static website.

Google Photos is an optional import source alongside choosing files directly from the Mac. The application uses the Google Photos Picker API so the artist chooses exactly which items to share. It does not request blanket access to the full Google Photos library.

How an import works

01 · Authorise

Connect Google Photos

The artist authorises the app in Google’s sign-in window.

02 · Choose

Pick specific media

Only items explicitly chosen in Google’s Picker are available for this import.

03 · Save locally

Choose a destination

Import as a gallery artwork or as supporting Studio Assets stored locally.

04 · Publish if wanted

Separate approval

Public artworks and approved supporting files are published only after a separate Git review, commit and push.

Important: Using the Google Photos Picker does not automatically publish a photograph. However, if the artist later publishes a selected file, the copy may become publicly accessible through the website and its public GitHub repository.

Why Google account access is requested

The application requests only the Google Photos Picker permission photospicker.mediaitems.readonly, to create a picking session and read the photos or videos you select. This is not general access to the Google Photos library.

Read our Google Photos Privacy Policy for what is stored, how an imported image can become public, how to disconnect, and how to request deletion. The Terms of Use describe the scope of this personal tool.
